# Skeleton — existing SRD 5.2.1 Undead visual research

**Canonical catalog ID:** `mon-srd-52-skeleton`, indexed before this batch; one product card in the existing Monsters gallery. No extra category/gallery.
**Shared anatomy:** `skeleton-warrior` original Gridborn bones/limbs, held weapon, source viewpoints and movement anchors, deterministically derived for Still/Idle/Move/Attack/Rest via `undead-family.mjs`.
**Distinct identity:** Ordinary SRD Skeleton remains anatomically skeletal—not a living fighter—with bleached bones, burial-rag cape, worn leather straps, skull fractures, corroded shield and sword. Open ribs and pelvis remain visible; Idle skull/arms twitch but never breathe; Rest collapsed and inert.
**Motion equipment:** Original skeletal weapon and shield group transform origins retained, with damage/weathering overlays drawn inside their respective animated groups.
**Not retail ready:** size-specific visual/art/weapon QA (32/64/128px), actual transparent VTT WebM/PNG export, Foundry/Roll20 import/playback, rights and checkout fulfillment. This PR only adds noncommercial SVG preview studies.
