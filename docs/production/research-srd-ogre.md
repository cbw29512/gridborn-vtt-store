# Ogre — Gridborn shared-body original design study
- **Official source:** SRD v5.2.1 `mon-srd-52-ogre`, the existing immutable monster card. The source names and types already exist in `src/monster-srd.js`.
- **Anatomy:** Derived from `assets/studies/cave-ogre.svg` and its matching four state assets without altering legs, shoulders, head proportions or the weapon attachment. Every source output is regenerated deterministically.
- **Visible role:** Classic Ogre wears an iron-strapped hide jerkin and simple iron brow helmet and carries a reinforced iron-bound club. Unlike the Cave Ogre's primitive stone club and undressed torso.
- **Actions:** Original heavy club slam / goblin blade strike, independently hand-linked to the shared source gear group. Original base limb stride and rest remain.
- **Requires:** actual human art-quality review (32/64/128px), no-weapon-over-face review, alpha transparent export, Foundry/Roll20 import, media certification and rights sign-off before retail. `purchasable=false`.
