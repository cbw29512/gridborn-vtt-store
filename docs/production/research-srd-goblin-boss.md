# Goblin Boss — Gridborn shared-body original design study
- **Official source:** SRD v5.2.1 `mon-srd-52-goblin-boss`, the existing immutable monster card. The source names and types already exist in `src/monster-srd.js`.
- **Anatomy:** Derived from `assets/studies/cave-goblin.svg` and its matching four state assets without altering legs, shoulders, head proportions or the weapon attachment. Every source output is regenerated deterministically.
- **Visible role:** Goblin Boss wears polished leather armor and a copper-plated jagged crown with a distinct larger sword and crossguard. Retains Goblin base pointed ears, visible face, sword hand and buckler.
- **Actions:** Original heavy club slam / goblin blade strike, independently hand-linked to the shared source gear group. Original base limb stride and rest remain.
- **Requires:** actual human art-quality review (32/64/128px), no-weapon-over-face review, alpha transparent export, Foundry/Roll20 import, media certification and rights sign-off before retail. `purchasable=false`.
